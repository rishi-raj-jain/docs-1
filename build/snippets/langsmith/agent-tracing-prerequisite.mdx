<Note>
In an [agent-based workspace](/langsmith/agents), [create an agent](/langsmith/create-an-agent) once before sending traces. Set `LANGSMITH_PROJECT`, or this integration's project setting, to the agent environment's [existing tracing project name](/langsmith/create-an-agent#use-an-environment-project). Replace example project names and overrides, including `default`, with that name. Configuring a destination does not register an agent.
</Note>
