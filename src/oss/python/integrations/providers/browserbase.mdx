[Browserbase](https://www.browserbase.com) runs cloud browsers for agents, with [session recordings](https://docs.browserbase.com/platform/browser/observability/observability) and a [live view](https://docs.browserbase.com/platform/browser/observability/session-live-view) for debugging. The same API key covers [Search](https://docs.browserbase.com/platform/search/overview) and [Fetch](https://docs.browserbase.com/platform/fetch/overview), which find and read pages without starting a browser session.

## Installation and setup

Get an API key from [Browserbase](https://www.browserbase.com) and set it as an environment variable:

```bash
export BROWSERBASE_API_KEY="your-browserbase-api-key"
```

Install the [Browserbase Python SDK](https://github.com/browserbase/sdk-python):

<CodeGroup>
```bash pip
pip install "browserbase>=1.21.0"
```

```bash uv
uv add "browserbase>=1.21.0"
```
</CodeGroup>

## Deep Agents

A [deep agent](/oss/deepagents/overview) can use Browserbase in two ways: a cloud browser that it drives through Stagehand tools, and Search and Fetch tools for pages that do not need a browser. For when to give an agent a browser, see [Browser use](/oss/deepagents/browser-use).

### Browser tools with Stagehand

The [Stagehand integration](/oss/integrations/tools/stagehand) runs an MCP server that gives the agent `run`, `snapshot`, and `screenshot` tools over one persistent browser session. To run that browser on Browserbase, set `STAGEHAND_BROWSER` to `browserbase` in the server's environment:

```python
import os

STAGEHAND_DIR = "/path/to/stagehand/packages/integrations/deepagents"

MCP_CONFIG = {
    "mcpServers": {
        "browser": {
            "command": "uv",
            "args": ["run", "--project", STAGEHAND_DIR, "--locked", "stagehand-deepagents-mcp"],
            "env": {
                "STAGEHAND_BROWSER": "browserbase",
                "BROWSERBASE_API_KEY": os.environ["BROWSERBASE_API_KEY"],
            },
        }
    }
}
```

For installation and the complete agent, see the [Stagehand integration](/oss/integrations/tools/stagehand#use-with-a-deep-agent).

### Search and fetch tools

Wrap Search and Fetch as tools so the agent finds and reads pages without a browser session. Fetch does not execute JavaScript.

Install the agent packages and set the model-provider credential before running this example:

```bash
pip install deepagents langchain-openai
export OPENAI_API_KEY="your-openai-api-key"
```

The example uses OpenAI's [GPT-5.5 snapshot](https://developers.openai.com/api/docs/models/gpt-5.5):

```python
import os

from browserbase import Browserbase
from deepagents import create_deep_agent
from langchain.tools import tool

bb = Browserbase(api_key=os.environ["BROWSERBASE_API_KEY"])


@tool
def web_search(query: str) -> str:
    """Search the web and return result titles and URLs."""
    response = bb.search.web(provider="parallel", query=query, num_results=5)
    return "\n".join(f"{result.title}: {result.url}" for result in response.results)


@tool
def fetch_page(url: str) -> str:
    """Fetch a page as markdown without opening a browser."""
    return bb.fetch_api.create(url=url, format="markdown").content


agent = create_deep_agent(
    model="openai:gpt-5.5-2026-04-23",
    tools=[web_search, fetch_page],
    system_prompt="Search to find pages, then fetch the pages you need to read.",
)
```

To let the agent open a browser for pages that need JavaScript or interaction, pass the Stagehand tools in the same list. Keep the `MCPAdapter` context open while the agent runs. For a complete example that combines Search, Fetch, and Stagehand, see Browserbase's [Deep Agents guide](https://docs.browserbase.com/integrations/langchain/deepagents).
