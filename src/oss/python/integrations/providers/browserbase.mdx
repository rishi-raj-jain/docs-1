[Browserbase](https://browserbase.com) provides cloud-hosted browser sessions for web automation. Use it to interact with rendered pages without managing a local browser.

Browserbase provides [identity and CAPTCHA-solving options](https://docs.browserbase.com/platform/identity/overview), [session recordings and logs](https://docs.browserbase.com/platform/browser/observability/observability), and a [live session view](https://docs.browserbase.com/platform/browser/observability/session-live-view) for debugging.

## Installation and setup

To use the [Browserbase Python SDK](https://github.com/browserbase/python-sdk):

1. Get an API key from [Browserbase](https://browserbase.com).
2. Set the `BROWSERBASE_API_KEY` environment variable:

   ```bash
   export BROWSERBASE_API_KEY="your-browserbase-api-key"
   ```

3. Install the SDK:

   ```bash
   pip install browserbase
   ```

## Deep Agents integration

For browser automation with [Deep Agents](/oss/deepagents/overview), use the [Stagehand v4 integration](/oss/integrations/tools/stagehand). It exposes `run`, `snapshot`, and `screenshot` tools through a persistent MCP session, with local Chrome or Browserbase as the browser.

See [Browser use](/oss/deepagents/browser-use) for use cases and browser selection. Follow the Stagehand integration guide for setup instructions and runnable upstream examples.
