To send traces to a specific project, use the [`LANGSMITH_PROJECT` environment variable](/langsmith/log-traces-to-project). If this is not set, LangSmith creates a default tracing project when it ingests the first trace. In an [agent-based workspace](/langsmith/agents), the first trace to a new project name, including the default project, creates an agent named after the project, with the project as its **Production** [environment](/langsmith/agent-environments). The agent's identifier is derived from the project name, so it can differ from the project name, and creating the agent requires permission to create projects. To name the agent and the environment directly instead, set `LANGSMITH_AGENT_ID` and `LANGSMITH_AGENT_ENVIRONMENT` in place of `LANGSMITH_PROJECT`. For details, see [Log traces to an agent](/langsmith/log-traces-to-agent).
